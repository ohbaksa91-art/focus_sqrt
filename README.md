# FOCUS · 오프라인 개인 기준 자세 측정

실행 장비는 Raspberry Pi 5 / Raspberry Pi OS Bookworm 64-bit입니다. Pi Camera Module 3(IMX708, CAM/DISP 1)는 측면, iPhone은 정면 입력입니다. 기존 nginx HTTPS와 SSH를 그대로 사용합니다. 인터넷·Supabase·Vercel 없이 Pi 내부 SQLite로 측정과 기록 조회가 동작합니다.

## 사용 흐름

1. `https://192.168.0.231/`에서 안내를 확인하고 참가자 ID로 입장합니다. 최초 안내 확인 여부와 참가자 ID는 브라우저의 서로 다른 키에 저장합니다.
2. Pi에 보이는 몸의 면(왼쪽/오른쪽), 실제 일반형/Wide 렌즈, 시작 대기(0·3·5·10초), 검출 깊이를 선택합니다. 렌즈를 모르면 임의로 일반형이라고 기록하지 말고 실제 제품을 확인하세요.
3. 측정 시작을 누르면 두 카메라가 위·아래로 표시됩니다. 시작 대기 취소, 촬영 가이드 표시/숨김, 음성 안내 켜기/끄기를 사용할 수 있습니다. 휴대폰이 아직 송신 중이 아니라면 HTTPS 모바일 화면에서 카메라 사용을 허용하세요. 구도를 맞춘 뒤 화면 하단에서 카운트다운 시작을 누릅니다.
4. 설정한 대기가 끝난 시점에 DB 세션을 생성합니다. 세션 전체 경과시간에는 인식 보류도 포함됩니다. 반복 횟수는 Pi 측면에서만 계산하고 정면 횟수를 합산하지 않습니다.
5. 지도자와 확인한 완료 동작 3회 이후 개인 기준을 저장할 수 있습니다. 측정 중 화면 하단의 개인 기준 버튼으로 엽니다.
6. 중지·저장을 누르면 SQLite에서 저장된 세션을 다시 읽어 결과를 표시합니다. 이전 기록을 다시 열거나 같은 조건의 시도와 비교하고 JSON·CSV로 내보낼 수 있습니다.

원본 영상과 사진은 저장하지 않습니다. 참가자 ID·시간별 측정값·반복·품질·촬영 조건·개인 기준 버전만 저장합니다. 같은 LAN의 사용자가 한 측정 세션을 공유하므로 현재 측정 참가자 ID를 확인하세요.

## 계산 정의

- **각도:** 640×480에 종횡비를 유지해 배치한 영상의 픽셀 좌표로 계산한 2D 투영각입니다. MediaPipe world 좌표의 3D 각도나 임상 관절가동범위가 아닙니다. 무릎은 고관절–무릎–발목, 고관절은 어깨–고관절–무릎, 몸통 기울기는 고관절→어깨 축과 영상 수직선의 각도입니다.
- **측면:** 선택한 몸의 면에 해당하는 어깨·고관절·무릎·발목을 사용합니다. 먼 쪽 관절이 보이지 않아도 같은 기준으로 탈락시키지 않습니다. 정면은 양쪽을 별도로 표시하며 실시간 요약값은 유효한 양쪽의 평균입니다.
- **반복 상태:** 선 자세 확인 → 하강 → 설정 깊이 → 선 자세 복귀 확인. 기본 연구용 값은 서기 160°, 하강 150°, 깊이 110°, 최소 ROM 30°, 최소 반복시간 1초, 최대 20초, 복귀 확인 0.25초입니다. 깊이는 화면에서 바꿀 수 있습니다.
- **ROM:** 하강 임계값 아래로 처음 내려간 프레임부터, 유효한 선 자세 복귀가 확인되는 구간의 첫 복귀 프레임까지 무릎 2D 각도의 최대−최소입니다.
- **반복시간:** 위 ROM과 정확히 같은 구간입니다. 첫 복귀 프레임 이후의 안정 확인 시간은 포함하지 않습니다. 시간은 Pi의 처리 시각 기준으로, 노출 시각의 정밀 동기화가 아닙니다.
- **보류:** 필요한 관절·구도가 유효하지 않으면 각도를 null로 저장하고 진행 중 반복을 버립니다. 1.25초보다 긴 입력 공백에도 같은 처리를 합니다. 정상 입력으로 돌아온 뒤 선 자세부터 다시 준비합니다. 공백은 null 표시를 남기고 그래프 선을 끊습니다.
- **개인 기준:** 현재 세션의 최근 완료 3회 ROM·시간 중앙값을 지도자 확인 체크 후 저장합니다. 참가자·측면·일반형/Wide·카메라/렌즈·측정 방식·반복 검출 설정 등 조건별로 나눕니다.
- **개인 기준 재현도:** `max(0, 100 × [1 − 0.7 × ROM 상대편차 − 0.3 × 반복시간 상대편차])`. 가중치는 검증 전 연구용입니다. 기준이 없으면 null이며, 기준 저장 이전 반복에는 소급하지 않습니다. 하강 시작 시점의 기준 ID·버전을 반복에 고정하므로 반복 중 기준이 바뀌어도 해당 반복의 기준은 바뀌지 않습니다.

재현도는 정답 자세·체력·피로 점수가 아닙니다. 비슷하게 움직인 것이 올바른 자세라는 뜻은 아니며, 잘못된 동작을 기준으로 저장하면 점수도 왜곡될 수 있습니다. 올바른 자세 평가는 문헌·전문가 검토와 별도 검증이 필요합니다. 두 영상은 동기화·3D 융합된 입력이 아닙니다.

## 촬영과 음성 안내

렌즈를 골반 높이 부근, 거리 약 2–3m에서 시험하는 것은 **초기 시험값**입니다. 검증된 표준이 아닙니다. 카메라를 고정·수평으로 놓고 서기와 가장 깊은 동작에서 머리·발이 모두 보이도록 조정하세요. 체형·공간·화각에 따라 바꾸고, Wide로 교체하면 거리·화면 가장자리 왜곡·각도 오차와 개인 기준을 다시 확인하세요.

중앙선·윤곽·발 위치 가이드는 촬영 보조이며 정답 자세의 뼈대가 아닙니다. 조명·역광·배경·복장·가구 가림을 점검하도록 안내하지만, 복장을 원인으로 확정하거나 체형을 분류하지 않습니다. 옷을 벗으라는 안내도 하지 않습니다.

음성은 브라우저의 한국어 SpeechSynthesis를 사용하며 온라인 TTS 서비스로 데이터를 보내지 않습니다. 카운트다운·시작·완료 횟수·지속 인식 보류·저장 완료를 안내합니다. 휴대폰에서 측정 시작 또는 음성 버튼을 직접 누른 뒤 사용할 수 있습니다. 한국어 음성의 설치 여부·볼륨·Safari 정책에 따라 소리가 나지 않을 수 있으며 숫자/문자 안내는 항상 표시합니다. 화면 잠금·백그라운드에서는 카메라가 중단될 수 있습니다.

## 저장·재시작·백업

DB 기본 위치는 `/home/focus/focus/data/focus.sqlite3`입니다. `FOCUS_DB_PATH`로 변경할 수 있습니다. WAL 모드를 사용하며 서비스 시작 시 미완료 세션은 interrupted로 복원합니다. 개인 기준과 과거 촬영 조건은 다시 켜도 유지됩니다. 대기만 하다 취소한 경우 실제 세션은 만들지 않습니다.

실행 중 백업은 파일 하나만 복사하는 대신 SQLite backup API를 사용하세요.

```bash
cd ~/focus
.venv/bin/python - <<'PY'
import sqlite3
from datetime import datetime
source=sqlite3.connect('data/focus.sqlite3')
target=sqlite3.connect('data/backup-'+datetime.now().strftime('%Y%m%d-%H%M%S')+'.sqlite3')
source.backup(target)
target.close()
source.close()
PY
```

`data/`, SSH 개인키, 인증서 개인키는 GitHub에 넣지 않습니다. GitHub는 코드 관리, Vercel은 별도 웹 배포, Supabase는 향후 온라인 백업/여러 장비 통합으로 검토할 수 있지만 현재 운영 의존성은 아닙니다.

## 설치·업데이트

기존 배포의 설정을 유지하려면 Mac에서 `scripts/deploy.sh 사용자@Pi주소 SSH키파일 [known_hosts파일]`을 사용하세요. 소스와 테스트를 전송하고 DB/모델/환경/기존 nginx 설정은 덮어쓰지 않습니다. 기존 서비스가 없다면 설치 스크립트로 최초 설치합니다.

`systemctl status focus nginx`, `journalctl -u focus`로 상태를 확인합니다. 실제 운영은 단일 worker입니다. 예전 `scripts/https.sh`는 내부 8000 포트를 직접 TLS로 바꾸는 구버전 도구이므로 현재 nginx HTTPS 구성에서 사용하지 마세요.
